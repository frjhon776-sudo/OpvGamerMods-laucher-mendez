## 📜 Términos & Condiciones

> **Al descargar, instalar o usar cualquier programa de este repositorio, aceptas todos los términos descritos a continuación.**

### 🛡️ 1. Antivirus
Debes quitar o desactivar el antivirus (o, como mínimo, agregar la carpeta del launcher a las exclusiones) para que el programa funcione correctamente.

### ⚔️ 2. Seguridad y falsos positivos
Nuestro programa no contiene virus ni ningún sistema que vulnere tu equipo con fines maliciosos. Debido a nuestro sistema **WARDEN**, cualquier antivirus puede detectar un falso positivo: es la protección que resguarda nuestro sistema y evita manipulaciones.

### 🔎 3. Acceso al sistema y recolección de información
Al aceptar estos términos, reconoces y aceptas que nuestro programa puede **leer y verificar información de tu sistema** (por ejemplo, procesos activos, archivos del launcher o configuración relacionada) como parte del funcionamiento de **WARDEN**. Esta información se recolecta **exclusivamente** para proteger al cliente y al usuario final frente a manipulaciones, trampas o uso indebido del software. No se usa con ningún otro fin, no se vende ni se comparte con terceros, y se trata de forma privada y confidencial.

### 🔍 4. Revisión de código
Si eres propietario de algún launcher o sistema, puedes hablar con el dueño de **NexusMzStudio** y solicitar una revisión breve de nuestro código privado.

### ⚠️ 5. Uso bajo tu propia responsabilidad
El uso de estos programas es voluntario y bajo responsabilidad del usuario. Si no estás de acuerdo con alguno de estos términos, no debes descargar, instalar ni usar los productos de este repositorio.
